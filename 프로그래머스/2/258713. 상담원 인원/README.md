# [level 2] 상담원 인원 - 258713

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/258713)

### 구분

코딩테스트 연습 > 2024 KAKAO WINTER INTERNSHIP

### 문제 설명

<p>유형별 상담원 인원을 n명 배정할 때 고객의 대기 시간 합이 최소가 되도록 하는 각 유형별 상담원 수를 return 하세요.</p>

<h5>제한사항</h5>

<ul>
<li>1 ≤ k ≤ 20 (유형 수)</li>
<li>1 ≤ n ≤ 20 (총 상담원 수)</li>
<li>1 ≤ reqs의 길이 ≤ 300</li>
</ul>

<h5>입출력 예</h5>

<table>
  <thead><tr><th>k</th><th>n</th><th>reqs</th><th>result</th></tr></thead>
  <tbody>
    <tr><td>2</td><td>3</td><td>[[1,3,2],[4,2,1],[5,5,2],[7,2,2]]</td><td>[1,2]</td></tr>
  </tbody>
</table>
