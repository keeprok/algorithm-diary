# [level 2] 보석 쇼핑 - 67258

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/67258)

### 구분

코딩테스트 연습 > 2020 카카오 인턴십

### 문제 설명

<p>보석 가게에서 모든 종류의 보석을 하나 이상 포함하는 가장 짧은 구간을 구하세요. 구간의 시작과 끝 인덱스를 1-indexed로 return 합니다.</p>

<h5>제한사항</h5>

<ul>
<li>1 ≤ gems의 길이 ≤ 100,000</li>
<li>gems[i]는 알파벳 대문자로만 이루어진 문자열</li>
</ul>

<h5>입출력 예</h5>

<table>
  <thead><tr><th>gems</th><th>result</th></tr></thead>
  <tbody>
    <tr><td>["DIA", "RUBY", "RUBY", "DIA", "DIA", "EMERALD", "EMERALD", "RUBY"]</td><td>[3, 7]</td></tr>
    <tr><td>["AA", "AB", "AC", "AA", "AC"]</td><td>[1, 3]</td></tr>
    <tr><td>["XYZ", "XYZ", "XYZ"]</td><td>[1, 1]</td></tr>
  </tbody>
</table>
