# [level 2] 당구 연습 - 169198

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/169198)

### 구분

코딩테스트 연습 > 연습문제

### 문제 설명

<p>당구대 위의 큐볼이 벽에 한 번 반사된 후 목표 공을 맞추는 최단 거리를 구하세요. 각 목표 공에 대한 최단 거리를 배열로 return 합니다.</p>

<h5>제한사항</h5>

<ul>
<li>1 ≤ m, n ≤ 1,000 (당구대 크기)</li>
<li>balls의 길이 ≤ 1,000</li>
</ul>

<h5>입출력 예</h5>

<table>
  <thead><tr><th>m</th><th>n</th><th>startX</th><th>startY</th><th>balls</th><th>result</th></tr></thead>
  <tbody>
    <tr><td>10</td><td>10</td><td>3</td><td>7</td><td>[[7, 7], [2, 7], [7, 3]]</td><td>[8, 10, 8]</td></tr>
  </tbody>
</table>
