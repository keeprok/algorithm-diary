# [level 2] 디펜스 게임 - 142085

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/142085)

### 구분

코딩테스트 연습 > 힙（Heap）

### 문제 설명

<p>n명의 병사와 k번의 무적권이 있을 때, 매 라운드마다 enemy[i]명의 적이 등장합니다. 병사로 막거나 무적권을 사용해 막을 수 있으며, 병사가 부족하면 게임이 끝납니다. 최대 몇 라운드까지 진행할 수 있는지 return 하세요.</p>

<h5>입출력 예</h5>

<table>
  <thead><tr><th>n</th><th>k</th><th>enemy</th><th>result</th></tr></thead>
  <tbody>
    <tr><td>7</td><td>3</td><td>[4,2,4,5,3,3,1]</td><td>5</td></tr>
    <tr><td>2</td><td>4</td><td>[3,3,3,3]</td><td>4</td></tr>
  </tbody>
</table>
